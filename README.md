# برنامج أرشفة ديوان جمعية حقنا (Haqna Diwan Archiver)

برنامج ديوان مخصص لجمعية حقنا يعمل على أرشفة البريد الصادر والوارد (ملفات PDF) مع واجهة رسومية ممتازة وتوليد أرقام وتواريخ تلقائية. البرنامج مبني بلغة C++ باستخدام إطار عمل Qt 5 ويعمل على كل من Windows و Linux.

## المميزات
- واجهة مستخدم رسومية حديثة باللغة العربية (من اليمين إلى اليسار).
- دعم لإضافة أرشيف للبريد "الوارد" والبريد "الصادر".
- توليد أرقام تسلسلية تلقائية لكل نوع من أنواع البريد.
- إدراج التاريخ تلقائيًا.
- أرشفة ونسخ ملفات الـ PDF بأمان إلى مجلد خاص (`Haqna_Archive` في مستندات المستخدم) وتسميتها بأرقام وتواريخ مميزة لمنع التكرار.
- قاعدة بيانات SQLite محلية ومدمجة لحفظ كافة بيانات المعاملات.
- جدول لعرض المعاملات المؤرشفة مع إمكانية فتح ملف الـ PDF بضغطة زر.

---

## المتطلبات الأساسية (Prerequisites)

لتشغيل وتطوير هذا البرنامج، ستحتاج إلى تثبيت **Qt 5** (مشتملًا على وحدات Core, GUI, SQL, Widgets) بالإضافة إلى مترجم **C++17** (مثل GCC, Clang, أو MSVC).

### على نظام Linux (Ubuntu/Debian)

افتح موجه الأوامر (Terminal) وقم بتنفيذ الأمر التالي لتثبيت الحزم المطلوبة:

```bash
sudo apt-get update
sudo apt-get install -y qtbase5-dev qt5-qmake qttools5-dev-tools libqt5sql5-sqlite g++ make
```

### على نظام Windows

1. قم بتحميل وتثبيت [Qt Online Installer](https://www.qt.io/download-qt-installer) من الموقع الرسمي.
2. أثناء التثبيت، اختر أحدث إصدار من Qt 5 (على سبيل المثال Qt 5.15.x).
3. تأكد من تحديد **MinGW** (مترجم C++) ضمن حزم التثبيت الخاصة بـ Qt 5.
4. (اختياري) يمكنك اختيار تثبيت Qt Creator لتسهيل عملية التعديل والبناء.

## طريقة البناء والتشغيل (Build and Run)

### باستخدام سطر الأوامر (Terminal / Command Prompt)

1. افتح موجه الأوامر وانتقل إلى مجلد المشروع الذي يحتوي على ملف `diwan.pro`.
2. قم بتوليد ملف `Makefile` باستخدام أداة `qmake`:
   ```bash
   qmake diwan.pro
   ```
3. قم ببناء المشروع:
   - **على Linux:**
     ```bash
     make
     ```
   - **على Windows (إذا كنت تستخدم MinGW):**
     ```bash
     mingw32-make
     ```
4. لتشغيل البرنامج بعد البناء:
   - **على Linux:**
     ```bash
     ./diwan
     ```
   - **على Windows:** ستجد الملف التنفيذي `diwan.exe` في مجلد البناء. انقر عليه نقرًا مزدوجًا.

### باستخدام Qt Creator (الطريقة الأسهل)

1. افتح برنامج **Qt Creator**.
2. اذهب إلى `File` -> `Open File or Project...` واختر ملف `diwan.pro`.
3. وافق على إعدادات الـ Kit الافتراضية.
4. اضغط على الزر الأخضر (Run) في أسفل اليسار، أو استخدم الاختصار `Ctrl+R` لبناء وتشغيل البرنامج فورًا.

## ملاحظات هامة

- **مكان حفظ الأرشيف:** سيتم إنشاء مجلد باسم `Haqna_Archive` تلقائيًا داخل مجلد المستندات (Documents) الخاص بك، حيث ستُنسخ إليه كافة ملفات الـ PDF التي يتم إضافتها.
- **قاعدة البيانات:** تُنشأ قاعدة البيانات SQLite بشكل تلقائي في مجلد بيانات التطبيق المخفية الخاصة بالنظام (على سبيل المثال `~/.local/share/diwan/` في لينكس) باسم `diwan.db`.
